#  FrontOffice UI — React Application (in progress)

Учебно-практический проект, создаваемый для отработки современных подходов к фронтенд-разработке и интеграции с микросервисной архитектурой.  
Проект находится в стадии активной разработки и регулярно обновляется.

---

##  Цели проекта

- Закрепить практические навыки работы с **React 18**, **Hooks**, **Context API** и **React Router**.
- Освоить настройку сборки с **Vite** и оптимизацию фронтенда для корпоративной экосистемы.
- Реализовать обмен данными с backend через **Kafka** и REST API.
- Практиковать CI/CD с **Bitbucket Pipelines** / **TeamCity**.

---

##  Технологический стек

- **Frontend:** React 18, Vite, TypeScript, CSS Modules
- **Backend (интеграция):** Node.js, Express
- **Инфраструктура:** Docker, Bitbucket, Kafka
- **Инструменты:** Git, ESLint, Prettier
